This file explains js/quiz.js.
quiz.js runs the Company Quiz page.
The pass mark is 16 correct answers out of 20.
The questions themselves live in questions.js, in the list companyQuizQuestions.

Lines 3 to 6 are variables used by the functions below.
Line 3: order is the list of question ids for this try. A new try shuffles that list.
Line 4: picks stores the answer the student chose for each question id.
Line 5: currentQuestion is the position in order. 0 means the first question.
Line 6: finished stops the result from being saved twice.
