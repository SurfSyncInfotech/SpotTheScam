This file explains js/install.js.
install.js manages Progressive Web App (PWA) installation and Service Worker registration.
It runs as an Immediately Invoked Function Expression (IIFE) to avoid polluting the global scope.

function alreadyInstalled()

Checks if the web application is already installed and running standalone:
- iOS standalone mode: window.navigator.standalone === true
- Standard modern browser display-mode: window.matchMedia("(display-mode: standalone)").matches

beforeinstallprompt Event
Line 25-29:
window.addEventListener("beforeinstallprompt", function (event) {
Fired by Chromium-based browsers (Chrome, Edge, Android) when the PWA meets installability criteria.
event.preventDefault() stops the automatic small mini-infobar so our custom header button can control the install flow.
waitingPrompt stores the event for later use.

Install Button Click Handler
Line 31-51:
button.addEventListener("click", function () {
When the user clicks the Install button:
1. If waitingPrompt is available:
   - waitingPrompt.prompt() displays the browser's native install dialog.
   - userChoice handles whether the user accepted or dismissed. If accepted, hides the button and note.
2. If waitingPrompt is not available (e.g., iOS Safari or unsupported browsers):
   - Shows the helpful fallback message in the note element:
   - For iOS: "On iPhone or iPad, tap Share, then tap Add to Home Screen."
   - For others: "Open the browser menu and choose Install app, or Add to Home Screen."
