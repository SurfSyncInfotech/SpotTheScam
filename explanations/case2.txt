This file explains js/case2.js.
case2.js runs Case 2, What Would You Do?
There are 20 situations. Every answer counts.
The student passes with 15 correct answers.
Case 2 stays locked until Case 1 has been passed.

Lines 3 to 9 are variables used by the functions below.
Line 3: questions is the list case2Scenarios from questions.js.
Line 4: currentQuestion is the position in that list. 0 is the first situation.
Line 5: selectedAnswer is the choice text for the situation on screen.
Line 6: score is the number of safe choices so far.
Line 7: records will hold the review for the result page.
Line 8: step is "choose", then "explain".
Line 9: finished stops the result from being saved twice.
